# DevOps Git Workflow

1. Update dev.
2. Create a feature branch.
3. Make configuration changes.
4. Inspect the Git diff.
5. Commit and push.
6. Open a pull request into dev.
7. Review and merge the changes.
8. Promote approved changes into main.
9. Tag stable releases.
10. Handle emergency changes through hotfix branches.

## Safety
Check file changes and scan for credentials.
